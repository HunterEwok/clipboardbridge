# الإجراءات السريعة

لمن يريد قفل حاسوب أو وضعه في السكون أو إعادة تشغيله من هاتف أو حاسوب آخر في المجموعة. ينفّذ المشرف الإجراء بنقرة واحدة أو أمر واحد؛ ولا ينفّذه الجهاز إلا إذا كان مستخدمه نفسه قد فعّل ذلك الإجراء عليه.

## الإجراءات

| الإجراء | ماذا يفعل | أين |
|---|---|---|
| `lock` | يقفل الشاشة | الحواسيب |
| `sleep` | يضع الحاسوب في السكون | الحواسيب |
| `reboot` | يعيد تشغيل الحاسوب بعد دقيقة | الحواسيب، والعضو الخفيف |
| `shutdown` | يطفئ الحاسوب بعد دقيقة | الحواسيب |
| `cancel-shutdown` | يلغي إعادة تشغيل أو إطفاء معلّقًا | الحواسيب، والعضو الخفيف |
| `restart` | يعيد تشغيل خدمة Clipboard Bridge | الحواسيب، والعضو الخفيف |
| إجراؤك الخاص | يشغّل برنامجًا اخترته، بصفة المستخدم المسجَّل دخوله | الحواسيب |

يمنح التنبيه قبل دقيقة من إعادة التشغيل أو الإطفاء كلَّ من أمام الحاسوب وقتًا لحفظ عمله أو تشغيل `cancel-shutdown`. وينبّه Windows كذلك المستخدمين المسجَّلين الدخول.

## فعّل إجراءً

على الجهاز، بصلاحية المسؤول (`sudo` على Linux وmacOS وFreeBSD):

```sh
cbb action                     # lists the actions and who may run each
sudo cbb action enable lock    # says what it allows and asks you to type yes
sudo cbb action enable reboot -by root,phone
sudo cbb action disable lock
```

يحدّد `-by` من يجوز له تشغيله: `root` و`phone` (هواتف المشرفين) و`computer` (حواسيب المشرفين) و`watch` (ساعة بمفتاح مشرف). وبدونه يجوز لكل مشرف. ولا يقبل `reboot` و`shutdown` إلا المشرفين الذين مفاتيحهم في العتاد، هاتفًا أو حاسوبًا فيه TPM، ما لم تضف `-any-key`.

على Linux يكتب التفعيل قاعدة polkit التي تمنح الخدمة بالضبط الحقوق التي تحتاج إليها الإجراءات المفعّلة، ويسحبها التعطيل.

## إجراء خاص بك

```sh
sudo cbb action add backup -by phone -- /usr/local/bin/backup.sh --quick
sudo cbb action remove backup
```

يشغّل وكيل المستخدم المسجَّل دخوله البرنامج بمساره الكامل، وبهذه الوسائط بالضبط ومن دون صدفة (shell). ولا يحصل المرسل إلا على حالة الخروج. ويجب أن ينتهي خلال 15 ثانية؛ وما يطول عن ذلك فشغّله في الخلفية.

## شغّل إجراءً

على حاسوب مشرف: `cbb action -on DEVICE NAME`، وهو يقول إن كان قد نُفِّذ أو لماذا لم يُنفَّذ.

على هاتف مشرف، افتح صفحة الجهاز وهو متصل واضغط الإجراء تحت «Quick actions»؛ يؤكده Face ID أو البصمة، وتطلب إعادة التشغيل والإطفاء تأكيدًا إضافيًا مرة. وتستطيع ساعة المشرف تشغيل الإجراءات المسموح بها لـ `watch`.

## أوقفها كلها

يوقف `sudo cbb action off` على الجهاز كل إجراء هناك. ومن مشرف، يفعل `cbb action off -on DEVICE` أو `-all` ذلك على جهاز آخر أو على كل الأجهزة، ويفعل «Turn all off» على الهاتف الشيء نفسه؛ ولا يعيد تفعيلها إلا مستخدم كل جهاز نفسه.

يحتفظ كل جهاز بسجل لآخر 100 إجراء طُلب منه تشغيلها، مع من طلبها ومتى.
