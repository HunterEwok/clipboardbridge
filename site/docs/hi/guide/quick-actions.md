# त्वरित क्रियाएँ

उनके लिए जो फ़ोन या समूह के किसी दूसरे कंप्यूटर से किसी कंप्यूटर को लॉक, स्लीप या रीस्टार्ट करना चाहते हैं। एडमिन एक टैप या एक कमांड से क्रिया चलाता है; डिवाइस उसे तभी चलाता है जब उसके अपने उपयोगकर्ता ने वहाँ वह क्रिया चालू की हो।

## क्रियाएँ

| क्रिया | क्या करती है | कहाँ |
|---|---|---|
| `lock` | स्क्रीन लॉक करती है | कंप्यूटर |
| `sleep` | कंप्यूटर को स्लीप में डालती है | कंप्यूटर |
| `reboot` | एक मिनट बाद कंप्यूटर को रीस्टार्ट करती है | कंप्यूटर, लाइट सदस्य |
| `shutdown` | एक मिनट बाद कंप्यूटर बंद करती है | कंप्यूटर |
| `cancel-shutdown` | लंबित रीबूट या शटडाउन रद्द करती है | कंप्यूटर, लाइट सदस्य |
| `restart` | Clipboard Bridge सेवा को रीस्टार्ट करती है | कंप्यूटर, लाइट सदस्य |
| आपकी अपनी | आपका चुना हुआ प्रोग्राम चलाती है, साइन इन उपयोगकर्ता के रूप में | कंप्यूटर |

रीबूट या शटडाउन से एक मिनट पहले की चेतावनी कंप्यूटर के पास किसी को भी अपना काम सहेजने या `cancel-shutdown` चलाने का समय देती है। Windows साइन इन उपयोगकर्ताओं को भी चेताता है।

## क्रिया चालू करें

डिवाइस पर, एडमिनिस्ट्रेटर के रूप में (Linux, macOS और FreeBSD पर `sudo`):

```sh
cbb action                     # lists the actions and who may run each
sudo cbb action enable lock    # says what it allows and asks you to type yes
sudo cbb action enable reboot -by root,phone
sudo cbb action disable lock
```

`-by` सीमित करता है कि कौन उसे चला सकता है: `root`, `phone` (एडमिन फ़ोन), `computer` (एडमिन कंप्यूटर), `watch` (एडमिन कुंजी वाली घड़ी)। इसके बिना हर एडमिन चला सकता है। `reboot` और `shutdown` केवल उन एडमिन को लेते हैं जिनकी कुंजियाँ हार्डवेयर में हैं, यानी फ़ोन या TPM वाला कंप्यूटर, जब तक आप `-any-key` न जोड़ें।

Linux पर, चालू करना वह polkit नियम लिखता है जो सेवा को ठीक वही अधिकार देता है जो चालू क्रियाओं को चाहिए, और बंद करना उन्हें वापस ले लेता है।

## आपकी अपनी क्रिया

```sh
sudo cbb action add backup -by phone -- /usr/local/bin/backup.sh --quick
sudo cbb action remove backup
```

साइन इन उपयोगकर्ता का एजेंट प्रोग्राम को उसके पूरे पाथ से, ठीक इन्हीं आर्ग्युमेंट के साथ और बिना शेल के चलाता है। भेजने वाले को केवल उसकी निकास स्थिति मिलती है। उसे 15 सेकंड के भीतर खत्म होना चाहिए; जो इससे लंबा हो उसे बैकग्राउंड में शुरू करें।

## क्रिया चलाएँ

एडमिन कंप्यूटर पर: `cbb action -on DEVICE NAME`, जो बताता है कि वह चली या क्यों नहीं।

एडमिन फ़ोन पर डिवाइस के ऑनलाइन रहते उसका पेज खोलें और "Quick actions" के नीचे क्रिया को टैप करें; Face ID या उँगली का निशान पुष्टि करता है, और रीबूट तथा शटडाउन एक बार और पूछते हैं। एडमिन घड़ी वे क्रियाएँ चला सकती है जिनकी `watch` के लिए अनुमति है।

## सब बंद करें

डिवाइस पर `sudo cbb action off` वहाँ हर क्रिया बंद कर देता है। एडमिन से `cbb action off -on DEVICE` या `-all` दूसरे डिवाइस पर या हर डिवाइस पर यह करता है, और फ़ोन पर "Turn all off" भी यही करता है; इन्हें दोबारा केवल हर डिवाइस का अपना उपयोगकर्ता चालू करता है।

हर डिवाइस उन आखिरी 100 क्रियाओं का लॉग रखता है जिन्हें चलाने को कहा गया, साथ में किसने कहा और कब।
