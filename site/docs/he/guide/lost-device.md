# אם מכשיר אבד או נגנב

למי שטלפון, מחשב או מכשיר אחר של הקבוצה שלו נעלם. הסירו אותו מהקבוצה בהקדם האפשרי; שאר המכשירים נשארים בקבוצה וממשיכים להסתנכרן.

## 1. הסירו אותו

בטלפון שהוא מנהל, הקישו על המכשיר שאבד ב**מסך הבית**, ואז על **Remove**. במחשב מנהל:

```sh
sudo cbb revoke NAME     # NAME, or the device ID, as cbb status shows it
```

כל מכשיר בקבוצה לומד על כך ומפסיק לדבר עם זה שאבד. רק השורש, או טלפון מנהל, מסיר מנהל.

## 2. אם זה היה מחשב מנהל: הקפיאו אותו קודם

המפתחות של מחשב מנהל יכולים לחתום. אם ייתכן שהוא בידיים של מישהו אחר, הקפיאו אותו מכל מנהל, כך ששום דבר שהוא חותם מעכשיו לא ייחשב, ואז הסירו אותו:

```sh
sudo cbb freeze NAME
```

מנהל קפוא לא יכול להקפיא את השורש או טלפון מנהל. אם הוא מקפיא בחזרה, שניהם נשארים קפואים עד שהשורש מחליט (‏`cbb unfreeze` או `cbb revoke` בשורש, או **Unfreeze** ו-**Remove** בטלפון השורש).

## 3. אם זה היה השורש: השתלטו על הקבוצה

השורש מחזיק את מפתח השורש של הקבוצה. כשהוא נעלם, מנהל הופך לשורש, וכל שאר המכשירים נשארים בקבוצה:

- עם טלפונים: בטלפון האחר, שהוא מנהל, הסירו את זה שאבד; האפליקציה משתלטת על הקבוצה באותו שלב;
- עם מחשבים: במחשב מנהל, ‏`sudo cbb takeover NAME`, כאשר NAME הוא השורש שאבד.

מכשירי iPhone שמשתמשים בקיצור דרך מזווגים שוב אחרי השתלטות. אם לא היה בקבוצה מנהל אחר, אי אפשר להשתלט עליה: צרו קבוצה חדשה והוסיפו את המכשירים מחדש. לכן האפליקציות מציעות טלפון מנהל שני, או מחשב מנהל, ברגע שיש בקבוצה מנהל יחיד.

## 4. כבו את מה שהוא יכול היה להגיע אליו

הסרת המכשיר מספיקה לקבוצה. אם אי אפשר להסיר אותו עדיין, או שרוצים להיות בטוחים לגבי המכשירים האחרים, מנהל יכול גם לכבות מרחוק:

| מה | פקודה במחשב מנהל |
|---|---|
| [הדבקה מרחוק](remote-paste.md) במכשיר, או בכולם | ‏`cbb paste-receive off -on DEVICE`, ‏`-all` |
| [פעולות מהירות](quick-actions.md) במכשיר, או בכולם | ‏`cbb action off -on DEVICE`, ‏`-all` |
| סנכרון מחוץ לבית במכשיר | ‏`cbb global off -on DEVICE` |

טלפון מנהל מציע את אותו הדבר בדף של המכשיר, וגם שעון מנהל יכול לשלוח אותם. רק המשתמש של כל מכשיר מפעיל אותם שוב.

## מה גנב מקבל

זה תלוי איפה המכשיר שמר את המפתחות שלו ([מפתחות ואימות](keys.md)):

- **מפתחות בחומרה** (טלפונים, מחשבי Linux עם TPM): אין מה להעתיק. המפתחות חותמים רק במכשיר הזה, והמפתחות של שורש ומנהל בטלפון חותמים רק אחרי הפנים, טביעת האצבע או קוד הגישה שלכם.
- **מפתחות בקובץ** (מחשבי Mac ו-Windows, מחשבי Linux בלי TPM, החבר הקל): מי שמעתיק את הקובץ יכול לפעול כאותו מכשיר עד שתסירו אותו. הצפינו את הדיסק (FileVault, ‏BitLocker, ‏LUKS) כדי שמכשיר גנוב לא יחשוף דבר.

היסטוריית לוח ההעתקה אינה נשמרת במכשירים, וסוד נעלם 60 שניות אחרי שהועתק.
