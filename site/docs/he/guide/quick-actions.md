# פעולות מהירות

למי שרוצה לנעול מחשב, להעביר אותו למצב שינה או להפעיל אותו מחדש מטלפון או ממחשב אחר בקבוצה. מנהל מריץ את הפעולה בהקשה אחת או בפקודה אחת; המכשיר מריץ אותה רק אם המשתמש שלו עצמו הפעיל את הפעולה הזאת שם.

## הפעולות

| פעולה | מה היא עושה | איפה |
|---|---|---|
| `lock` | נועלת את המסך | מחשבים |
| `sleep` | מעבירה את המחשב למצב שינה | מחשבים |
| `reboot` | מפעילה מחדש את המחשב כעבור דקה | מחשבים, החבר הקל |
| `shutdown` | מכבה את המחשב כעבור דקה | מחשבים |
| `cancel-shutdown` | מבטלת הפעלה מחדש או כיבוי שממתינים | מחשבים, החבר הקל |
| `restart` | מפעילה מחדש את שירות Clipboard Bridge | מחשבים, החבר הקל |
| משלכם | מריצה תוכנה שבחרתם, כמשתמש שמחובר | מחשבים |

אזהרה של דקה לפני הפעלה מחדש או כיבוי נותנת לכל מי שליד המחשב זמן לשמור את העבודה שלו או להריץ `cancel-shutdown`. ‏Windows גם מזהיר את המשתמשים המחוברים.

## הפעילו פעולה

במכשיר, כמנהל (‏`sudo` ב-Linux, ב-macOS וב-FreeBSD):

```sh
cbb action                     # lists the actions and who may run each
sudo cbb action enable lock    # says what it allows and asks you to type yes
sudo cbb action enable reboot -by root,phone
sudo cbb action disable lock
```

‏`-by` מגביל מי רשאי להריץ אותה: ‏`root`, ‏`phone` (טלפוני מנהלים), ‏`computer` (מחשבי מנהלים), ‏`watch` (שעון עם מפתח מנהל). בלעדיו כל מנהל רשאי. ‏`reboot` ו-`shutdown` מקבלים רק מנהלים שהמפתחות שלהם בחומרה, טלפון או מחשב עם TPM, אלא אם תוסיפו `-any-key`.

ב-Linux, ההפעלה כותבת את כלל ה-polkit שנותן לשירות בדיוק את ההרשאות שהפעולות הפועלות צריכות, והכיבוי לוקח אותן בחזרה.

## פעולה משלכם

```sh
sudo cbb action add backup -by phone -- /usr/local/bin/backup.sh --quick
sudo cbb action remove backup
```

הסוכן של המשתמש המחובר מריץ את התוכנה לפי הנתיב המלא שלה, עם הארגומנטים האלה בדיוק וללא shell. השולח מקבל רק את סטטוס היציאה שלה. היא חייבת להסתיים תוך 15 שניות; כל דבר ארוך יותר התחילו ברקע.

## הריצו פעולה

במחשב מנהל: ‏`cbb action -on DEVICE NAME`, שאומר אם היא רצה או למה לא.

בטלפון מנהל, פתחו את דף המכשיר כשהוא מחובר והקישו על הפעולה תחת "Quick actions"; ‏Face ID או טביעת האצבע מאשרים, והפעלה מחדש וכיבוי שואלים פעם נוספת. שעון מנהל יכול להריץ את הפעולות המותרות עבור `watch`.

## כבו את כולן

‏`sudo cbb action off` במכשיר מכבה שם כל פעולה. ממנהל, ‏`cbb action off -on DEVICE` או `-all` עושה זאת במכשיר אחר או בכולם, ו-"Turn all off" בטלפון עושה אותו דבר; רק המשתמש של כל מכשיר מפעיל אותן שוב.

כל מכשיר שומר יומן של 100 הפעולות האחרונות שביקשו ממנו להריץ, עם מי ביקש ומתי.
