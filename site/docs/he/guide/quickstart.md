# התחלה מהירה

Clipboard Bridge נותן לטלפון ולמחשבים שלך לוח העתקה אחד: מעתיקים באחד ומדביקים באחר. המכשירים יוצרים **קבוצה** ברשת הביתית שלך. הטלפון מחזיק את מפתח הקבוצה ומאשר כל מכשיר חדש, כך שאיש לא יכול להצטרף בלעדיך.

![הטלפון מוסיף כל מחשב באמצעות קוד ה-QR שלו; לאחר מכן המכשירים חולקים לוח העתקה אחד](../images/group.svg)

זה לוקח ארבעה שלבים: להתקין את האפליקציה, להתקין את Clipboard Bridge במחשב, לסרוק את קוד ה-QR של המחשב, ולהפעיל שיתוף באותו מחשב.

בלב הקבוצה יכול לעמוד מחשב, והיא יכולה גם להיות מורכבת מטלפונים בלבד: שתי האפשרויות פועלות, ואנחנו ממליצים על מחשב שדלוק לעיתים קרובות, שמשאיר את הסנכרון מחוץ לבית זמין בכל עת ([שני סוגי קבוצות](how-it-works.md#two-kinds-of-group)). עם טלפונים בלבד, דלגו על שלבים 2 עד 4: בכל טלפון נוסף הקישו על **I already use Clipboard Bridge on another phone**, וסרקו את הקוד שהוא מציג באמצעות **Connect a new device** בטלפון הראשון (**+** אחרי שכבר יש בו מכשירים).

## 1. התקינו את האפליקציה בטלפון

- **Android** 10 ומעלה: הורידו את `clipboardbridge-X.Y.Z.apk` מ[הגרסה האחרונה](https://github.com/HunterEwok/clipboardbridge/releases/latest) ישירות בטלפון ופתחו אותו; כש-Android שואל, אפשרו לדפדפן להתקין אפליקציות.
- **iPhone**: האפליקציה תגיע דרך TestFlight, שעדיין לא נפתח. עד אז iPhone משתמש בקיצור דרך, ומחשב מחזיק את הקבוצה: ראו [בלי האפליקציה](without-app.md).

פתחו את האפליקציה. את המחשב הראשון תוסיפו בשלב 3.

## 2. התקינו את Clipboard Bridge במחשב

בחרו כל מחשב ברשת הביתית שלכם: מחשב נייד, מחשב שולחני, Raspberry Pi.

ב-**Linux** או ב-**Mac**, בטרמינל:

```sh
curl -fsSL https://github.com/HunterEwok/clipboardbridge/releases/latest/download/get.sh | sudo sh
```

ב-**Windows** 10 או 11, ב-PowerShell שנפתח באמצעות "Run as administrator":

```powershell
irm https://github.com/HunterEwok/clipboardbridge/releases/latest/download/get.ps1 | iex
```

תוכנית ההתקנה בודקת את ההורדה, מפעילה את Clipboard Bridge ושואלת שתי שאלות: האם לפתוח בשבילו את חומת האש (ענו `y`) והאם להתעדכן אוטומטית (`y` היא תשובה טובה גם כאן). לאחר מכן התנתקו והתחברו מחדש פעם אחת, או פתחו טרמינל חדש ב-Windows. Homebrew, winget, Docker והפרטים נמצאים ב[התקנה](install.md).

## 3. הוסיפו את המחשב

במחשב:

```sh
sudo cbb pair
```

ב-Windows, הריצו את `cbb pair` בטרמינל של מנהל. הוא מציג קוד QR.

באפליקציה הקישו על **Connect a new device** וסרקו את הקוד. האפליקציה יוצרת את מפתח הקבוצה (היא מבקשת טביעת אצבע, פנים או קוד גישה) ומוסיפה את המחשב. זו הקבוצה.

הוסיפו כל מחשב אחר באותה דרך: התקנה, `sudo cbb pair`, ו-**+** באפליקציה.

## 4. שתפו את לוח ההעתקה של המחשב

מחשב חדש שומר את לוח ההעתקה שלו לעצמו עד שתגידו אחרת. כדי שמה שתעתיקו בו יגיע לקבוצה, ומה שהקבוצה מעתיקה יגיע אליו:

```sh
sudo cbb mode shared
```

ב-Windows, הריצו את `cbb mode shared` בטרמינל של מנהל.

עכשיו העתיקו במחשב והדביקו בטלפון, או להפך:

- **Android** מקבל את ההעתקות של המחשבים מעצמו. כדי לשלוח את ההעתקות של הטלפון, הקישו על הכפתור הגדול במסך הבית של האפליקציה, על האריח **Send clipboard** בהגדרות המהירות, או על Send בהתראה; או הפעילו **Send my copies by themselves** באפליקציה כדי שזה ייעשה בשבילכם.
- **בין מחשבים** במצב משותף: מעתיקים באחד ומדביקים באחר. אין על מה ללחוץ.

מצבים אחרים (קבלה בלבד, שליחה בלבד) מפורטים ב[פקודות](../reference/cli.md#cbb) (`cbb mode`), ושאר מה שהאפליקציות עושות ב[אפליקציות](apps.md).

## 5. מומלץ: תנו למחשב שתמיד דלוק לעזור לטלפון

הקבוצה פועלת גם עם הטלפון בלבד, אבל שני דברים טובים יותר במחשב שנשאר דלוק, כמו שרת ביתי, Raspberry Pi או מחשב שולחני:

- **הפכו אותו למנהל.** בטלפון הקישו על המחשב במסך הבית ואז על **Make it an admin**. Mac, מחשב Windows או מחשב Linux בלי TPM שומרים את המפתחות בקובץ, והאפליקציה מזהירה אתכם על כך קודם ([מפתחות](keys.md#the-three-levels)). אז הוא יכול גם להוסיף ולהסיר מכשירים (`sudo cbb pair`, `sudo cbb revoke NAME`), כך שאין צורך שהטלפון יהיה בהישג יד בכל פעם. הטלפון נשאר השורש של הקבוצה, המכשיר המהימן ביותר שלה: מפתח השורש לעולם לא עוזב את שבב האבטחה של הטלפון.
- **הפכו אותו לרכזת**, כדי שהמכשירים שלכם ימשיכו להסתנכרן כשהם מחוץ לבית. ראו [מחוץ לבית](away-from-home.md).

הוסיפו גם טלפון שני, כדי שאובדן טלפון אחד לא יאבד דבר: בטלפון השני הקישו על **I already use Clipboard Bridge on another phone** וסרקו את הקוד שלו עם **+** בראשון. הטלפון הראשון הופך אותו למנהל.
