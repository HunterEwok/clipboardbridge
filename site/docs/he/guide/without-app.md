# בלי האפליקציה

קבוצה לא צריכה את אפליקציית הטלפון. מחשב יכול להחזיק את הקבוצה, ו-iPhone בלי האפליקציה מצטרף באמצעות קיצור דרך. זו גם הדרך כל עוד אפליקציית ה-iPhone ממתינה ל-TestFlight.

![מחשב Linux מחזיק את הקבוצה ומוסיף את ה-Mac ואת Windows בקוד בן שש ספרות, ואת ה-iPhone בפרופיל ובקיצור דרך](../images/without-app.svg)

## 1. צור את הקבוצה במחשב

[התקן](install.md) את Clipboard Bridge במחשב שדלוק לעיתים קרובות: Linux, Windows, Mac או FreeBSD. הוא מחזיק את הקבוצה ומגיש את קיצור הדרך של ה-iPhone. אחר כך:

```sh
sudo cbb new
```

המחשב הזה הוא עכשיו ה**שורש** של הקבוצה: הוא מחזיק את מפתח הקבוצה ומוסיף ומסיר מכשירים. המפתח שלו הוא קובץ במחשב, מוגן על ידי המערכת; אפליקציית הטלפון שומרת את אותו מפתח בשבב האבטחה של הטלפון.

## 2. הוסף מחשבים

בשורש:

```sh
sudo cbb pair
```

הוא מציג קוד בן שש ספרות וממתין. במחשב החדש הרץ גם כן `sudo cbb pair`: הוא מציג קודם קוד QR לאפליקציית הטלפון, שאפשר להתעלם ממנו, ומבקש את הקוד; הקלד שם את שש הספרות. המחשב החדש מצטרף תוך שניות.

אחר כך הפעל שיתוף בכל מחשב, כמו ב[התחלה מהירה](quickstart.md#4-share-the-computers-clipboard): `sudo cbb mode shared`.

## 3. הוסף iPhone בעזרת קיצור הדרך

בשורש, או במחשב מנהל שעונה ל-`clipboardbridge.local` (‏`cbb status` אומר אם הוא עונה):

```sh
sudo cbb pair -phone
```

הוא מדפיס קוד QR, את תחילת טביעת האצבע וקוד בן שש ספרות.

1. סרוק את קוד ה-QR במצלמת ה-iPhone ופעל לפי הדף: התקן את הפרופיל.
2. בדוק שטביעת האצבע של הפרופיל מתחילה כמו זו שהודפסה (הגדרות, כללי, VPN וניהול מכשירים, "Clipboard Bridge", פרטים נוספים), ואז הפעל אמון מלא בו (הגדרות, כללי, אודות, הגדרות אמון בתעודות).
3. הוסף את קיצור הדרך "clipboardbridge" מאותו דף והרץ אותו פעם אחת; הוא מבקש את הקוד בן שש הספרות.
4. הצב את קיצור הדרך על לחצן הפעולה, או על הקשה על הגב (הגדרות, נגישות, מגע, הקשה על הגב, הקשה כפולה).

לחיצה אחת בוחרת אז את הכיוון בעצמה: מה שהועתק במחשב לפני רגע מגיע ל-iPhone; אחרת, העתקה חדשה ב-iPhone הולכת למחשבים.

## 4. אל תסתמך על מחשב אחד

הפוך מחשב שני למנהל, כדי שגם הוא יוכל להוסיף ולהסיר מכשירים:

```sh
sudo cbb admin NAME                   # on the root; NAME as cbb status shows it, and it must be on
sudo cbb admin -allow-file-key NAME   # for a Mac, a Windows PC or a Linux computer without a TPM
```

מחשב Linux עם TPM שומר שם את מפתח המנהל. Mac, מחשב Windows או מחשב Linux בלי TPM שומרים אותו בקובץ, ולכן `cbb admin` דורש קודם `-allow-file-key`: מי שמעתיק את הקובץ הזה פועל כמנהל עד שמנהל אחר מסיר את המחשב, ולכן הפוך למנהל רק מחשב ששמור אצלך היטב.

אם השורש אבד או התקלקל, המנהל משתלט על הקבוצה, וכל שאר המכשירים נשארים:

```sh
sudo cbb takeover NAME       # on the admin; NAME is the lost root
```

מכשירי iPhone עם קיצור הדרך מותאמים מחדש לאחר השתלטות. עוד ב[אם מכשיר אבד או נגנב](lost-device.md).

## הצטרפות מרשת אחרת

מחשב שאינו בבית מצטרף בהזמנה מהרכזת ([מחוץ לבית](away-from-home.md#a-computer-that-is-not-at-home-an-invitation)), או דרך חיבור שאתה כבר שולט בו:

- **SSH** אל השורש או אל מנהל: במחשב החדש הרץ `ssh -N -L 18764:localhost:8764 user@that-machine`, ואז `sudo cbb pair` שם (בהפעלת SSH אחרת) ו-`sudo cbb pair -code 127.0.0.1:18764` כאן.
- **VPN משלך** שנותן לשתי המכונות כתובות פרטיות: `sudo cbb pair` בשורש או במנהל, ואז `sudo cbb pair -code ITS-VPN-ADDRESS:8764` כאן. ב-Linux, הרץ את המתקין שוב אחרי הגדרת ה-VPN, כדי שכללי חומת האש שלו יתירו את רשת ה-VPN.

הקוד אף פעם לא עובר בגלוי: ההתאמה מתבצעת בתוך SSH או ה-VPN שלך, ובתוך TLS. המחשב החדש מסתנכרן בנתיב הזה עד שהשירות שלו מופעל מחדש; כדי להמשיך לסנכרן אחר כך, הפעל [סנכרון מחוץ לבית](away-from-home.md) בשניהם לפני שאתה סוגר את החיבור.

## קבוצה מלפני 0.4

לקבוצה שנוצרה לפני 0.4 אין שורש: כל חבר Linux ו-Windows מחזיק את המפתחות שלו. כשכל המכשירים מריצים 0.4 ומעלה, תן לה שורש, באחד מהם; איש לא מתאים מחדש, חוץ ממכשירי iPhone עם קיצור הדרך:

```sh
sudo cbb upgrade
```
