# Быстрые действия

Для тех, кто хочет заблокировать, усыпить или перезагрузить компьютер с телефона или другого
компьютера группы. Администратор запускает действие одним нажатием или одной командой;
устройство выполняет его, только если его собственный пользователь включил там это действие.

## Действия

| Действие | Что делает | Где |
|---|---|---|
| `lock` | блокирует экран | компьютеры |
| `sleep` | переводит компьютер в сон | компьютеры |
| `reboot` | перезагружает компьютер через минуту | компьютеры, лёгкий участник |
| `shutdown` | выключает компьютер через минуту | компьютеры |
| `cancel-shutdown` | отменяет ожидающую перезагрузку или выключение | компьютеры, лёгкий участник |
| `restart` | перезапускает службу Clipboard Bridge | компьютеры, лёгкий участник |
| ваше собственное | запускает выбранную вами программу от имени вошедшего пользователя | компьютеры |

Минута предупреждения перед перезагрузкой или выключением даёт тому, кто сидит за компьютером,
время сохранить работу или выполнить `cancel-shutdown`. Windows ещё и предупреждает
вошедших пользователей.

## Включите действие

На устройстве, от имени администратора (`sudo` в Linux, macOS и FreeBSD):

```sh
cbb action                     # lists the actions and who may run each
sudo cbb action enable lock    # says what it allows and asks you to type yes
sudo cbb action enable reboot -by root,phone
sudo cbb action disable lock
```

`-by` ограничивает, кто может его запускать: `root`, `phone` (телефоны-администраторы),
`computer` (компьютеры-администраторы), `watch` (часы с ключом администратора). Без него может
любой администратор. `reboot` и `shutdown` принимают только администраторов, чьи ключи лежат в
аппаратной части: телефон или компьютер с TPM, если только вы не добавите `-any-key`.

В Linux включение записывает правило polkit, которое даёт службе ровно те права, которые нужны
включённым действиям, а выключение их забирает.

## Собственное действие

```sh
sudo cbb action add backup -by phone -- /usr/local/bin/backup.sh --quick
sudo cbb action remove backup
```

Агент вошедшего пользователя запускает программу по полному пути, ровно с этими аргументами и
без оболочки. Отправитель получает только код завершения. Она должна завершиться за 15 секунд;
всё более долгое запускайте в фоне.

## Запустите действие

На компьютере-администраторе: `cbb action -on DEVICE NAME`, он сообщает, выполнилось ли
действие или почему нет.

На телефоне-администраторе откройте страницу устройства, пока оно в сети, и нажмите действие в
разделе «Быстрые действия»; подтверждает его Face ID или отпечаток пальца, а перезагрузка и
выключение спрашивают ещё раз. Часы-администратор могут запускать действия, разрешённые для
`watch`.

## Выключите их все

`sudo cbb action off` на устройстве выключает там все действия. С администратора
`cbb action off -on DEVICE` или `-all` делает это на другом устройстве или на каждом, а
«Выключить все» на телефоне делает то же самое; снова включить их может только пользователь
самого устройства.

Каждое устройство хранит журнал последних 100 действий, которые его просили выполнить, с
указанием, кто просил и когда.
