# Без приложения

Группе из компьютеров не нужно приложение на телефоне: группу может держать компьютер.

![Компьютер с Linux держит группу и добавляет Mac и Windows по шестизначному коду](../images/without-app.svg)

## 1. Создайте группу на компьютере

[Установите](install.md) Copy Beyond Borders на компьютер, который часто включён: Linux,
Windows, Mac или FreeBSD. Он держит группу. Затем:

```sh
sudo cbb new
```

Теперь этот компьютер — **корень** группы: он хранит ключ группы и добавляет и удаляет
устройства. Его ключ — это файл на компьютере, защищённый системой; приложение на телефоне
хранит такой же ключ в защищённом чипе телефона.

## 2. Добавьте компьютеры

На корне:

```sh
sudo cbb pair
```

Он показывает шестизначный код и ждёт. На новом компьютере тоже выполните `sudo cbb pair`:
сначала он показывает QR-код для приложения на телефоне, который можно проигнорировать, и
просит код; введите там шесть цифр. Новый компьютер входит в группу за несколько секунд.

Затем каждый компьютер синхронизируется сам, как в [быстром старте](quickstart.md#4-copy-on-one-paste-on-another).

## 3. Не зависьте от одного компьютера

Сделайте второй компьютер администратором, чтобы он тоже мог добавлять и удалять устройства:

```sh
sudo cbb admin NAME                   # on the root; NAME as cbb status shows it, and it must be on
sudo cbb admin -allow-file-key NAME   # for a computer without a TPM or a Secure Enclave
```

Компьютер с Linux или ПК с Windows с TPM хранит свой ключ администратора в нём, Mac — в
Secure Enclave. Компьютер без них хранит его в файле, поэтому `cbb admin` сначала требует `-allow-file-key`: кто
скопирует этот файл, действует как администратор, пока другой администратор не удалит
компьютер, так что делайте администратором только тот компьютер, который вы бережёте.

Если корень потерян или сломан, группу забирает администратор, а все остальные устройства
остаются:

```sh
sudo cbb takeover NAME       # on the admin; NAME is the lost root
```

Подробнее — в разделе
[если устройство потеряно или украдено](lost-device.md).

## Вход из другой сети

Компьютер, который не дома, входит по приглашению от хаба
([Вне дома](away-from-home.md#a-computer-that-is-not-at-home-an-invitation)) или через
соединение, которое вы уже контролируете:

- **SSH** к корню или администратору: на новом компьютере выполните
  `ssh -N -L 18764:localhost:8764 user@that-machine`, затем там (в другом сеансе SSH)
  `sudo cbb pair`, а здесь `sudo cbb pair -code 127.0.0.1:18764`.
- **Собственный VPN**, дающий обеим машинам частные адреса: `sudo cbb pair` на корне или
  администраторе, затем здесь `sudo cbb pair -code ITS-VPN-ADDRESS:8764`. В Linux после
  настройки VPN запустите установщик снова, чтобы его правила брандмауэра разрешили сеть VPN.

Код никогда не идёт открытым текстом: сопряжение проходит внутри SSH или вашего VPN и внутри
TLS. Новый компьютер синхронизируется по этому пути, пока не перезапустится его служба; чтобы
синхронизация продолжалась после этого, включите [синхронизацию вне дома](away-from-home.md)
на обоих, прежде чем закрыть соединение.

## Группа, созданная до 0.6

0.6 читает только записи группы версии 2 и не умеет возвращаться к старым группам. Компьютер,
обновлённый с более ранней версии, при первом запуске выходит из старой группы: переносит её
файлы в `before-0.6` в своём каталоге состояния, сохраняет настройки, и `cbb status` сообщает
об этом. Создайте группу заново: `cbb new` на одном компьютере, затем `cbb pair` на остальных.
