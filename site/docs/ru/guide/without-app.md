# Без приложения

Группе не обязательно приложение на телефоне. Группу может держать компьютер, а iPhone без
приложения входит через быструю команду. Это же путь, пока приложение для iPhone ждёт
TestFlight.

![Компьютер с Linux держит группу и добавляет Mac и Windows по шестизначному коду, а iPhone — по профилю и быстрой команде](../images/without-app.svg)

## 1. Создайте группу на компьютере

[Установите](install.md) Clipboard Bridge на компьютер, который часто включён: Linux,
Windows, Mac или FreeBSD. Он держит группу и обслуживает быструю команду для iPhone. Затем:

```sh
sudo cbb new
```

Теперь этот компьютер — **корень** группы: он хранит ключ группы и добавляет и удаляет
устройства. Его ключ — это файл на компьютере, защищённый системой; приложение на телефоне
хранит такой же ключ в защищённом чипе телефона.

## 2. Добавьте компьютеры

На корне:

```sh
sudo cbb pair
```

Он показывает шестизначный код и ждёт. На новом компьютере тоже выполните `sudo cbb pair`:
сначала он показывает QR-код для приложения на телефоне, который можно проигнорировать, и
просит код; введите там шесть цифр. Новый компьютер входит в группу за несколько секунд.

Затем включите общий доступ на каждом компьютере, как в [быстром старте](quickstart.md#4-share-the-computers-clipboard):
`sudo cbb mode shared`.

## 3. Добавьте iPhone через быструю команду

На корне или на компьютере-администраторе, который отвечает за `clipboardbridge.local`
(`cbb status` сообщает, так ли это):

```sh
sudo cbb pair -phone
```

Он печатает QR-код, начало отпечатка и шестизначный код.

1. Отсканируйте QR-код камерой iPhone и следуйте странице: установите профиль.
2. Проверьте, что отпечаток профиля начинается с напечатанного (Настройки, Основные, VPN и
   управление устройством, «Clipboard Bridge», Подробнее), затем включите для него полное
   доверие (Настройки, Основные, Об этом устройстве, Доверие сертификатам).
3. Добавьте быструю команду «clipboardbridge» с той же страницы и запустите её один раз; она
   спросит шестизначный код.
4. Назначьте быструю команду на кнопку «Действие» или на касание задней панели (Настройки,
   Универсальный доступ, Касание, Касание задней панели, Двойное касание).

Одно нажатие дальше само выбирает направление: то, что только что скопировали на компьютере,
приходит на iPhone; иначе новая копия на iPhone уходит на компьютеры.

## 4. Не зависьте от одного компьютера

Сделайте второй компьютер администратором, чтобы он тоже мог добавлять и удалять устройства:

```sh
sudo cbb admin NAME                   # on the root; NAME as cbb status shows it, and it must be on
sudo cbb admin -allow-file-key NAME   # for a Mac, a Windows PC or a Linux computer without a TPM
```

Компьютер с Linux и TPM хранит свой ключ администратора в нём. Mac, ПК с Windows или компьютер
с Linux без TPM хранит его в файле, поэтому `cbb admin` сначала требует `-allow-file-key`: кто
скопирует этот файл, действует как администратор, пока другой администратор не удалит
компьютер, так что делайте администратором только тот компьютер, который вы бережёте.

Если корень потерян или сломан, группу забирает администратор, а все остальные устройства
остаются:

```sh
sudo cbb takeover NAME       # on the admin; NAME is the lost root
```

iPhone с быстрой командой после захвата входят в группу заново. Подробнее — в разделе
[если устройство потеряно или украдено](lost-device.md).

## Вход из другой сети

Компьютер, который не дома, входит по приглашению от хаба
([Вне дома](away-from-home.md#a-computer-that-is-not-at-home-an-invitation)) или через
соединение, которое вы уже контролируете:

- **SSH** к корню или администратору: на новом компьютере выполните
  `ssh -N -L 18764:localhost:8764 user@that-machine`, затем там (в другом сеансе SSH)
  `sudo cbb pair`, а здесь `sudo cbb pair -code 127.0.0.1:18764`.
- **Собственный VPN**, дающий обеим машинам частные адреса: `sudo cbb pair` на корне или
  администраторе, затем здесь `sudo cbb pair -code ITS-VPN-ADDRESS:8764`. В Linux после
  настройки VPN запустите установщик снова, чтобы его правила брандмауэра разрешили сеть VPN.

Код никогда не идёт открытым текстом: сопряжение проходит внутри SSH или вашего VPN и внутри
TLS. Новый компьютер синхронизируется по этому пути, пока не перезапустится его служба; чтобы
синхронизация продолжалась после этого, включите [синхронизацию вне дома](away-from-home.md)
на обоих, прежде чем закрыть соединение.

## Группа, созданная до 0.4

У группы, созданной до 0.4, нет корня: ключи хранит каждый участник на Linux и Windows. Когда
на всех устройствах работает 0.4 или новее, дайте ей корень на одном из них; заново никто не
сопрягается, кроме iPhone с быстрой командой:

```sh
sudo cbb upgrade
```
